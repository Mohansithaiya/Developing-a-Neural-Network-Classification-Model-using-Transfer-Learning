# Neural Network Classification Using Transfer Learning

An image classification project built with **PyTorch** using **transfer learning with the VGG19 architecture**.

The project demonstrates how a pretrained deep learning model can be adapted to a new image classification task by reusing learned visual features and modifying the final classification layer for the target dataset.

### What's Inside

* VGG19 pretrained model
* Transfer learning for image classification
* Dataset preprocessing and image loading
* Modified fully connected classification layer
* Training and validation loss visualization
* Confusion matrix evaluation
* Classification report
* Prediction on new sample images

### Built With

**Python · PyTorch · VGG19 · NumPy · Matplotlib · Scikit-learn**

### Project Files

The complete implementation, dataset processing, pretrained model setup, training process, evaluation results, visualizations, and sample prediction are available in the uploaded project file.

### Outcome

The pretrained VGG19 model is successfully adapted for the target classification task using transfer learning. The trained model is evaluated using training and validation loss, a confusion matrix, and a classification report.
